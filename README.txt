# README

## Project Overview
This is a simple HTML and CSS-based website containing multiple pages and assets organized into different folders. The project includes essential web pages such as an account page, dashboard, product listing, settings, and reports.

## Folder Structure
```
/project-root
│── Css/             # Contains all CSS stylesheets
│── images/          # Stores website images
│── account.html     # Account management page
│── dashboard.html   # Main dashboard page
│── product.html     # Product listing page
│── setting.html     # User settings page
│── report.html      # Reports and analytics page
│── index.html       # Homepage (if applicable)
│── README.md        # Project documentation (this file)
```

## Installation & Usage
1. Download and extract the ZIP file.
2. Open `index.html` or `dashboard.html` in a web browser.
3. Ensure the `Css` and `images` folders remain in the same directory as the HTML files for proper styling and image loading.

## Technologies Used
- **HTML**: Structure of the web pages
- **CSS**: Styling and layout
